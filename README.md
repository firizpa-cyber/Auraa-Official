# Auraa

A Nuxt application built with Vue 3 and TypeScript.

## Tech stack

- Nuxt 4
- Vue 3
- TypeScript
- Tailwind CSS 4
- GSAP
- libSQL client
- Nodemailer

## Requirements

- Node.js
- npm, pnpm, yarn, or Bun

## Getting started

```bash
git clone https://github.com/firizpa-cyber/Auraa-Official.git
cd Auraa-Official
npm install
npm run dev
```

The development server runs on port `3001`.

## Production

```bash
npm run build
npm run preview
```
